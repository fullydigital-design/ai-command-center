# AI Command Center

Local AI workstation dashboard for RTX setups.

## Stack
React 18 + TypeScript + Vite 6 + Tailwind CSS v4
FastAPI + psutil + pynvml (Python backend)
Tauri v2 (desktop wrapper)

## Key rules
- Never rewrite full files — use targeted edits only
- No hardcoded paths — use relative paths or env vars
- Backend is partially stubbed — frontend works fully on mock data
